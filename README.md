# Контент Pixel Swap

Пікселарт, карти зон і каталог, які гра докачує після релізу. Роздається
GitHub Pages — сервера тут немає, це просто статичні файли.

```
v1/catalog.json      список наборів і картинок, числа рівнів, розміри файлів
v1/art/<id>.png      сам пікселарт, 128×128
v1/zones/<id>.zbin   запечений поділ на зони
```

Теку збирає `tools/publish.py` з основного репозиторію гри. Руками тут нічого
не редагується: джерело правди — каталог гри.

Навіщо запечені зони: порахувати поділ для 128×128 коштує близько секунди на
настільній машині й до чотирьох на телефоні. Готовий файл читається за шість
мілісекунд.
